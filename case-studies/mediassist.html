MediAssist AI

Health conversations and tracking in one workspace.

What it addresses

Brings health-related conversations and personal tracking tools into one prototype interface, with separate modes for different kinds of questions.

Four modes

Symptoms, medication discussion, mental wellness and lab-report discussion use separate prompts. Symptom matching can supply reference context to the chat workflow.

Application structure

The updated source uses Node.js, Express, MongoDB/Mongoose and Gemini. Models cover chat messages, medications, appointments, mood logs, health logs, vitals and disease reference records. The project includes Docker and Compose files.

Implementation details

The chat route validates mode and input, limits message/history length, applies request timeouts and retries transient failures. API keys are configured on the backend rather than displayed on the portfolio.

Evidence and status

This page uses the latest MongoDB-based project folder and a real frontend capture. Source and setup files were inspected. A hosted demo is now available; Gemini calls and database persistence have not been independently validated in this portfolio review.

Limitations

MediAssist is an educational prototype, not a clinically validated service or medical device. Its outputs require professional review. Authentication, health-data privacy, generated-content handling and end-to-end tests require further assessment before real-world use.
